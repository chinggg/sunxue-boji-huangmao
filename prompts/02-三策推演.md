# Prompt 02 · 三策推演

> 孙宇晨在访谈里给的具体做法：
> 先用 2–4 个月积累数据，然后把数据喂给**不同的**顶尖大模型，
> 让它们从上、中、下三策里给出突破路径，**取其中策或最优解去执行**，
> 并在执行中根据反馈持续 Tuning。

**为什么是中策**：上策往往依赖不可复制的资源，下策收益不足。
中策是普通人够得着的最优解。

---

````
你是一位战略推演助手。我会给你我过去一段时间积累的真实数据。

请基于这些数据，给我三条突破现状的路径：上策、中策、下策。

我的数据：
【把你的 health-data.md / daily.md 内容整段粘贴到这里】

我的约束条件：
- 可投入时间：每周【   】小时
- 可投入资金：每月【   】元
- 不可触碰的底线：【    】
- 地理位置是否可变动：【可 / 不可】

对每一策，按以下字段输出：

| 字段 | 说明 |
|---|---|
| 策略核心 | 一句话 |
| 具体动作 | 分周列出，第 1 周到第 8 周 |
| 所需资源 | 时间、钱、人脉、技能 |
| 依赖的不可复制资源 | 如果没有，写「无」 |
| 预期收益 R（0–10） | 并说明量级（是线性收益还是指数收益） |
| 实现概率 P（0–1） | 并说明你为什么估这个值 |
| 直接成本 C（0–10） | |
| 评价成本 E（0–10） | 父母/同事/同学会不会反对，强度多大 |
| 切换成本 S（0–10） | 需要放弃什么 |
| ROI | 直接算出 (R × P) / (C + E + S) |
| 失败模式 | 这一策最可能怎么死 |
| 止损条件 | 出现什么信号就该撤 |

然后给出：
1. **推荐**：三策里推荐哪一策，为什么（不要默认推荐上策）。
2. **Tuning 机制**：每两周应该看哪 3 个指标来判断要不要调整。
3. **7 天内可立刻开始的最小动作**：必须是一件今天下午就能做的事。

约束：
- 三策必须是真正不同的路径，不能是同一条路的三个力度版本。
- 如果数据不足以支撑某一策，明说。
- 不给投资/医疗建议。
````

## 多模型交叉验证

同一份数据，分别发给 Claude / GPT / Gemini，然后对比：

```markdown
## 三策交叉验证 · 【日期】

| 模型 | 推荐策 | ROI 估值 | 分歧点 |
|---|---|---|---|
| Claude | 中策 | 0.38 | 认为上策依赖人脉不可复制 |
| GPT   | 上策 | 0.52 | 高估了我的人脉兑现率 |
| Gemini| 中策 | 0.41 | 指出中策的止损点更清晰 |

**收敛结论**：取中策。分歧集中在「人脉能否兑现」，
我用一条可验证的方式验证：【    】
```

> 让不同的模型对同一份数据打架，比让一个模型自圆其说有用得多。
