# Prompt 04 · 训练渐进超载规划

> 渐进式超载（Progressive Overload）是薄肌系统里唯一的硬指标。
> 没有渐进超载，你只是在「活动」，不是在「训练」。

---

## 用法 A · 有训练视频

````
你是我的力量训练记录与规划助手。我上传一段训练视频（或逐组文字记录）。

请识别并输出：
1. 动作名称（深蹲 / 硬拉 / 卧推 / 划船 / 推举 / 其他）
2. 组数 × 每组次数 × 每组重量
3. 动作质量评估：有没有明显代偿、幅度不足、锁定不充分
4. 本次总容量（volume = 重量 × 次数 × 组数）

然后基于**渐进式超载原则**规划下一次训练：
- 如果本次能标准完成目标次数的全部组 → 下次 +2.5 kg（下肢）或 +1.25 kg（上肢）
- 如果只能完成部分组 → 维持重量，补满次数
- 如果动作质量下滑 → 减重 10%，先修质量

我的数据：
- 体重【  】kg，体脂率【  】%
- 训练目标：薄肌态（精瘦、线条分明、不显壮）
- 每周可训练【  】次，每次【  】分钟
- 器械条件：【健身房 / 家庭哑铃 / 纯自重】

输出格式：直接给我一张下次训练的计划表（动作 × 组数 × 次数 × 重量）。
````

## 用法 B · 纯文字记录

````
我本周的训练记录如下：
- 周一：深蹲 60kg × 5 × 4组（第4组只做了3次）；卧推 40kg × 8 × 3组
- 周三：硬拉 70kg × 5 × 4组（全部完成）；划船 35kg × 10 × 3组
- 周五：深蹲 60kg × 5 × 4组（全部完成）；推举 25kg × 8 × 3组（第3组勉强）

请：
1. 算出本周总容量，并与上周对比（我上周深蹲总容量是 1150kg）
2. 判断哪些动作进入「可加重量」状态，哪些需要维持
3. 给出下周完整计划表
4. 指出我当前计划里缺失的环节（例如：缺少髋铰链/缺少上肢拉/核心不足）
````

```markdown
|---|---|---|---|---|---|---|

```

## 薄肌训练原则

| 原则 | 说明 |
|---|---|
| **复合动作优先** | 深蹲、硬拉、卧推、划船、推举 ≥ 60% 训练量 |
| **渐进超载是核心** | 每周必须有一次「比上周多一点」 |
| **每次 30 分钟** | 可循环比强度重要 |
| **孤立动作次要** | 弯举、飞鸟是点缀，不是主项 |
| **不为观众训练** | 不做镜子里的动作 |

## 进阶规则

```
若 连续两周 无法完成渐进超载：
  → 检查睡眠（<7h 是首要嫌疑）
  → 检查蛋白质（<1.6 g/kg 是第二嫌疑）
  → 检查热量缺口（>500 kcal 是第三嫌疑）
  → 三者都正常 → 安排一周 deload（减量 40%）
```

> ⚠️ 出现关节疼痛、头晕、异常心律，**立刻停止并就医**。本 Prompt 不构成医疗建议。
