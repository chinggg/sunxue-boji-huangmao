# Prompt 05 · 全图插眼：推演 100 个赛道

> 不要闭门造车，不要急于下决定，而是先做「探图」。
> 就像玩 RTS 或 MOBA 一样，**先造几个移动速度极快的侦察兵去插眼**。

**目标**：用 AI 逐一推演未来 10 年 100 个专业 / 行业的趋势，把地图全开。

---

## 主 Prompt

````
你是我的「侦察兵」。我要做一次全图插眼：推演未来 10 年不同专业与行业的趋势。

请不要给我结论，先给我**地图**。

对每一个赛道，按以下字段输出一行（后续我会让你做成表格）：

| 字段 | 取值 |
|---|---|
| 赛道名称 | |
| 10 年需求曲线 | 扩张 / 平稳 / 萎缩 |
| AI 替代风险 | 高 / 中 / 低（附一句理由） |
| 准入门槛 | 先天条件 / 长期学历 / 短期培训 / 无门槛 |
| 边际成本 | 一份时间能否多次变现（是 / 否） |
| 地理约束 | 必须绑定某地 / 可远程 / 完全自由 |
| 复利属性 | 经验是否可积累（强 / 中 / 弱） |
| 当前饱和度 | 红海 / 竞争正常 / 蓝海 |

我的背景：
- 年龄【  】，当前专业/行业【    】
- 可投入的转型时间【  】个月
- 可承受的收入中断【  】个月
- 不擅长的方向：【    】
- 明确不想做的：【    】

请按以下批次输出，每次不要超过 20 个赛道：
  第 1 批：与我的当前专业最邻近的 20 个
  第 2 批：AI 直接冲击的 20 个
  第 3 批：AI 创造的 20 个新岗位
  第 4 批：地理套利相关（可远程 / 出海）的 20 个
  第 5 批：你认为我漏掉的 20 个

全部输出后，给我：
1. **一张完整表格**（100 行）
2. **Top 10 推荐**：按「扩张 + 低 AI 替代风险 + 强复利 + 弱地理约束」排序
3. **我的 Benchmark**：这 100 个里，综合指标的**前 3 名**是什么？
   （我要用它作为 37% 参照系决策的参照系）
4. **三个反直觉发现**：哪些赛道看起来热但其实在萎缩？哪些看起来冷但在扩张？
````

## 为什么需要 100 个

| 数量 | 问题 |
|---|---|
| 看 3 个 | 参照系缺失 → 盲定 |
| 看 20 个 | 刚够建立初步 Benchmark |
| **看 100 个** | 地图全开，能看见资源与风险的**分布**，而不只是几个点 |
| 看 200 个 | 边际收益递减，进入选择瘫痪区 |

## 决策衔接

拿到 Benchmark 后，用 37% 规则：

```bash
python3 scripts/sunxue.py 37
```

- 前 37%（约前 30 个）：**只看不定**，唯一用途是建立 Benchmark
- 从第 31 个开始：一旦出现综合指标超过参照系的最优解 → **立刻出手**

## 一个深刻的附带命题

> 如果在 AI 时代，人类的知识、数学证明或历史文化
> 没有被形式化并上传网络成为 AI 的训练语料，
> 那么这段文明在下一纪元**等同于未曾发生过**。

**推论**：把这份 100 赛道推演**写下来、公开、结构化**。
这不是在做内容，是在为你的认知做形式化存档。

## 复利用法

每季度重跑一次这份推演，diff 两次结果：

```markdown
## 全图插眼 · 季度 diff

| 赛道 | 上季 | 本季 | 变化 |
|---|---|---|---|
| AI Agent 工程 | 蓝海 | 竞争正常 | 窗口在关 |
| 数据标注 | 扩张 | 平稳 | AI 已经开始自我标注 |
```

> 地图会变。**保持 Small Ego，及时打补丁。**
