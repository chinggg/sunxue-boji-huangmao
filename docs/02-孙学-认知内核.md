# 02 · 孙学：认知内核

> 三样东西不是并列关系。
> 孙学是内核，薄肌和黄毛是跑在这个内核上的两个应用。

---

## 2.1 定义

**孙学 = 投入产出比（ROI）最大化。能赢就行，过程中别人怎么评价，不计入成本。**

拆成两个半句：

- **前半句（方法论）**：ROI 最大化 —— 这是一套可计算的决策框架
- **后半句（成本观）**：他人评价不计入成本 —— 这是一次会计制度的修改

大多数人以为孙学的精髓是「不择手段」，其实不是。
**精髓是把一项从来没人计入的成本科目，明确地划掉。**

---

## 2.2 会计革命：把「评价」移出成本表

传统决策的隐性成本结构：

```
C(action) = C(task) + C(face) + C(permission)
             任务成本    面子成本     许可成本
                          ↑            ↑
                    别人会怎么看    我是不是还不够格
```

孙学的操作是：

```
C(action) = C(task) + 0 + 0
```

这意味着**大量原本 NPV 为负的动作，瞬间变成正 NPV**。

> 你不需要变得更勇敢，你只需要修改你的会计科目表。

### 真实案例

**巴菲特午餐（2019）**
456 万美元拍下，转头说肾结石去不了，全球媒体追着跑，最后还是去奥马哈吃了。
外界的解读：丢人现眼、蹭热度。
会计视角：用极低的精神维护成本，把全网流量剥削得干干净净。

**苏富比香蕉（2024）**
620 万美元买下一根胶带香蕉，跑到香港当着记者面剥皮吃掉。
外界的解读：人傻钱多。
会计视角：一次行为艺术，买断全球媒体头条。

> 传统体面是折旧资产，他直接清零，换全网注意力。

## 2.3 孙学的六个可操作内核

### 内核 1 · 先自由，后财富

> 很多人陷入一个迷思：以为只有赚到了足够多的钱，自己才能获得自由。
> **事实恰恰相反。**

自由 = 主观认知的解绑定 + 行动的机动性。
财富 = 认知自由之后套利成功的**伴生品**，不是前提。

推论：**30 岁前不买房、不买车、不过早锁定流动性。**
一旦买房买车，你的地理位置与现金流就被死死定在一个地方。
当远方出现巨大风口时，你会因为要照顾本地固定资产而错失。

### 内核 2 · 三不主义

不买房 · 不买车 · 不早婚 —— 不是禁欲，是**流动性管理**。

| 项目 | 表面属性 | 孙学属性 |
|---|---|---|
| 房子 | 资产 | **债务枷锁**（锁死地理位置） |
| 车 | 便利 | **持续消耗品**（折旧 + 占用注意力） |
| 早婚 | 归宿 | **合伙束缚**（现金流绑定） |

### 内核 3 · 时间第一原则

> 拒绝所有消耗时间的低效琐事。
> 打车替代开车，把通勤时间用于思考、学习、认知变现。

判断标准：**这件事能不能被外包、被自动化、被删除？**

### 内核 4 · 只押注爆发前夜

行业已经成熟不要进，完全空白风险太高。
要找**需求真实、尚未被主流认可、即将起飞**的赛道。

赛道五条军规（来自《财富自由革命之路》）：

1. **抓住爆发前夜的红利** —— 风来之前先站到风口
2. **赛道够长、速度够快** —— 年增速 ≥ 20%，且能连续 10–20 年
3. **病毒式扩散能力** —— 一处跑通能迅速复制（代码复制成本≈0，米其林大厨不能）
4. **需求刚到骨子里** —— 从人性深处找，不是从品类表里找
5. **拥抱不确定性** —— 波动是机会，允许小成本试错

> 慢车道上开法拉利，也跑不过快车道上的自行车。

### 内核 5 · 四层杠杆递进

```
体力 → 技能 → 产品 → 生态
卖时间  卖能力  卖副本  卖共识
```

- 认知杠杆（信息差）：普通人最容易上手
- 网络杠杆（个人品牌）：自媒体，边际成本为零，可无限加杠杆
- 资本杠杆：低成本资金投优质资产
- 自动化杠杆：产品/系统/流程，脱离个人持续盈利

> 财富本质：**共识价值**。创造大众认可的共识，比单纯生产产品赚钱更快。

### 内核 6 · 横向复利

> 每件事比同行强 1%，多维度同时领先 1%。

纵向复利是积累，横向复利是**多维叠加**。
严防两件事：**一次性亏损**，和**中途清零**。

## 2.4 财富自由的真实定义

**财富自由 ≠ 钱多躺平**

财富自由 = **不再为钱出售自己的时间、注意力、尊严和情绪**。

即「四个不妥协」：

| 不妥协 | 含义 |
|---|---|
| 时间 | 不为钱让渡可支配时间 |
| 注意力 | 不为钱让渡专注力 |
| 情感 | 不为钱委屈关系 |
| 尊严 | 不为钱低头 |

> 财富不是目的，是**拒绝的底气**。
