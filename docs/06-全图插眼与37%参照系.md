# 06 · 全图插眼与 37% 参照系

> 在 AI 时代，绝大多数行业都会被重塑，**唯有人的寿命与时间不可复制**。
> 所以机会遍地都是 —— 关键是你有没有把地图打开。

---

## 6.1 全图插眼

### 6.1.1 从 RTS/MOBA 借来的思维模型

> 不要闭门造车，不要急于下决定，而是先做「探图」。
> 就像玩 RTS 或 MOBA 一样，**先造几个移动速度极快的侦察兵去插眼**。

| 游戏概念 | 现实映射 |
|---|---|
| 战争迷雾 | 你对行业/专业的无知区域 |
| 侦察兵（移动速度快、成本低） | AI 推演、信息检索、低成本试探 |
| 插眼 | 建立可复用的 Benchmark 数据点 |
| 开图 | 看清资源与风险的分布 |
| 主力出击 | 在看清地图后再投入重资源 |

### 6.1.2 具体动作：推演 100 个专业

> 年轻人可以利用 AI，逐一推演未来 10 年 **100 个不同专业**的就业与行业趋势，
> 把地图全开，看见资源与风险分布后再做选择。

**操作模板**（见 [`prompts/05-全图插眼100专业.md`](../prompts/05-全图插眼100专业.md)）

对每个专业/赛道，让 AI 输出：

| 字段 | 说明 |
|---|---|
| 10 年需求曲线 | 扩张 / 平稳 / 萎缩 |
| AI 替代风险 | 高 / 中 / 低，及理由 |
| 准入门槛 | 是否需要先天条件或长期学历投入 |
| 边际成本 | 一份时间能否多次变现 |
| 地理约束 | 是否必须绑定某地 |
| 复利属性 | 经验是否可积累 |

100 个点铺完，你手里就有了一张**别人没有的地图**。

### 6.1.3 AI 已经打碎了学术圈层壁垒

> 过去很多顶尖成果依赖于复杂的圈层资源，但现在 AI 正打碎这种壁垒。

**案例**：纽约大学一位教授在研究千禧年数学难题之一的 NS 方程（Navier–Stokes equations），
把核心思路分享给 OpenAI 后，OpenAI 调集 **700 万美元算力 + 数千个 Agent 节点**，
**仅用时两天**就沿该思路攻克了推导。

推论：**年轻研究者借助 AI，能够直接跨越传统硕博体制的漫长积累，产生世界级突破。**

### 6.1.4 一个深刻的信息论命题

> 如果在 AI 时代，人类的知识、数学证明或历史文化
> **没有被形式化（Formally Verified）并上传网络成为 AI 的训练语料**，
> 那么这段文明与历史在下一纪元**等同于未曾发生过**。

**推论（对个人的直接指导）**：
把你学到的东西**写下来、公开、结构化**。
这不是在做内容，这是在**为你的认知做形式化存档**。
不被形式化的认知，在下一纪元不存在。

## 6.2 37% 参照系决策模型

### 6.2.1 模型

面对 N 个选项（100 套房 / 100 个专业 / 100 份 offer）：

```
① 前 37%（约前 30 个）：只看不定
   └── 唯一用途：建立 Benchmark（参照系）

② 从第 31 个开始：一旦出现综合指标超过参照系的最优解
   └── 立刻出手
```

### 6.2.2 为什么是 37%

这是经典最优停止问题（Secretary Problem）的渐近解 `1/e ≈ 0.368`。
它的直观含义：

- **样本太少就决定** → 参照系没建立，你不知道什么是「好」
- **看完全部才决定** → 最优解已经过去了，且陷入选择瘫痪

### 6.2.3 两种失败模式

| 失败模式 | 表现 | 根因 |
|---|---|---|
| **盲定** | 第一套就下手 | 参照系缺失，被局部最优骗 |
| **瘫痪** | 看满 100 套还是不定 | 沉没成本谬误 + 选择过载 |

> 大部分人决策失败，要么是第一套就盲目下定，
> 要么是看了 100 套因选择瘫痪而错过最优解。

### 6.2.4 计算器

```bash
$ python3 scripts/sunxue.py 37
选项总数 [100]：50
已考察数量 [18]：18

── 37% 参照系诊断 ──────────────────
  参照系门槛：18 个（50 × 37%）
  当前进度：18 / 50
  状态：✅ 参照系已建立，进入决策区
  当前 Benchmark：第 3 名
  建议：从第 19 个起，遇到超过 Benchmark 的立刻出手
```

**记住**：从第 4 到第 6 个一旦出现超越参照系的最优解，**立刻出手**。

## 6.3 全球套利：逐水草而居

### 6.3.1 API 区域差价

同一种 AI 服务的 API，在阿根廷、土耳其、尼日利亚等地区
与在美国的定价存在**巨大差价**。

做全球 Token 中转站或跨国需求匹配，就能产生合法的商业价值。

### 6.3.2 客户基数重估

> 把全人类 **80 亿人**，以及未来几十亿**硅基 Agent**，都当成潜在客户。

### 6.3.3 流动性纪律

> 强烈建议年轻人在 30 岁之前**不买房、不买车、不过早锁定流动性**。

一旦锁定，你的地理位置与现金流被死死定在一个地方。
当远方（硅谷、某个新兴市场）出现巨大风口时，
你会因为要照顾本地固定资产或小额稳定工作而错失。

**原则：保持轻资产与高机动性。哪里生产力回报高，就把身体与资产转移到哪里。**

## 6.4 决策清单

做重大决策前，逐条打勾：

- [ ] 我是否已经建立了 Benchmark（至少看过 37% 的选项）？
- [ ] 我的判断是基于数据，还是基于情绪/面子？
- [ ] 这个决定会不会锁死我的地理位置或现金流？
- [ ] 五年后，谁会记得这件事？
- [ ] 反对者的反对基于数据还是情绪？
- [ ] 这个选项的边际成本是否趋近于零（可复制）？
- [ ] 我是否在为「被羡慕」付钱，还是在为「最后站着」付钱？
