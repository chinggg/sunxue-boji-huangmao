# 07 · 肌肉资产负债表

> 把身体当成一家公司来读报表。
> 你会发现「减肥」这个词，从一开始就问错了问题。

## 7.1 身体的三张表

### 资产负债表

| 科目 | 类别 | 说明 |
|---|---|---|
| 骨骼肌量 | **资产 · 现金储备** | 应激时可兑付：大病/高压时代谢优先扣肌肉去修复黏膜与器官 |
| 心肺功能 | **资产 · 产能** | 决定你的最大输出功率 |
| 体脂 | **负债 · 不良** | 占额度、不生息，且提高维护成本 |
| 内脏脂肪 | **负债 · 高危** | 直接关联代谢综合征 |
| 骨密度 | **资产 · 固定资产** | 折旧慢，但一旦折完不可恢复 |

> **肌肉就是你身上的美金存量。**
> 如果平时的「肌肉存款」不足，一场大病就会直接让碳基服务器崩盘。

### 利润表（每日）

```
收入 = 摄入热量
支出 = 基础代谢 + 活动消耗 + 食物热效应 + 肌肉被动消耗
结余 = 收入 − 支出
```

**关键**：肌肉是被动燃脂的「红莲斗篷」——
即使在睡觉时也在持续消耗热量、改善胰岛素敏感性。

→ **肌肉量越高，你的每日固定支出越高。**
减脂的难度，本质上取决于你的资产负债表结构，而不是你的意志力。

### 现金流量表

```
经营现金流 = 每日训练与饮食管理的投入（利息支出）
投资现金流 = 抗阻训练带来的肌肉增量
筹资现金流 = 睡眠、恢复、蛋白质摄入
```

> 大肌肉 = 高存量 + **高利息**（训练时长、饮食管理、补剂成本全部超标）
> 薄肌 = 足够存量 + 低利息 → **长期净现值最高**

只有抗阻训练能同时兼顾心肺与肌肉。

## 7.4 ⚠️ 药物减重的会计欺诈

### 恶性循环链条

```
司美格鲁肽
   │
   ▼
脂肪减少 ✅ + 肌肉大幅脱落 ❌
   │
   ▼
基础代谢率（Metabolism）断崖式下跌
   │
   ▼
停药 → 迅速反弹（因为「炉子」变小了）
   │
   ▼
肌肉更少 → 代谢更低
   │
   ▼
晚年肌无力 → 极易骨折 → 卧床
```

**会计视角**：
药物让你在**利润表**上短暂好看（体重下降），
同时悄悄掏空你的**资产负债表**（肌肉储备）。
这是典型的**表外亏损**。

> 马斯克依赖司美格鲁肽降重，是典型的恶性循环。

**正确顺序**：先通过抗阻训练把「现金储备」（肌肉）建起来，
再谈热量缺口。顺序反了，减的是资产不是负债。

## 7.5 主动排雷：无症状也要查

> 主动健康管理与被动急救的本质区别 ——
> **在无症状时通过 AI 排雷**，配合抗阻训练构建肌肉资产。

| 频率 | 项目 |
|---|---|
| **每 3 个月** | 体重、体脂率、骨骼肌量、腰围；力量指标（深蹲/硬拉 5RM） |
| **每 6 个月** | 血脂四项、空腹血糖、糖化血红蛋白、肝肾功能、尿酸 |
| **每年** | 高敏 CRP、睾酮、甲功、维生素 D、铁蛋白；腹部超声 |
| **每 2–3 年** | DEXA 骨密度（35 岁后） |

**执行方式**：把结果抄进 `templates/health-data.md`，
交给 AI 做趋势分析 —— 它比任何一次单点体检都更有价值。

> 孙宇晨本人就是第一个「没有任何身体症状、纯粹由 AI 驱动」
> 来做主动排雷的人 —— 接诊医生当场问他是不是用了 AI。

## 7.6 目标配置：薄肌态的参数区间

| 指标 | 男性参考区间 | 女性参考区间 | 说明 |
|---|---|---|---|
| 体脂率 | 12–18% | 20–26% | 线条显形且不显壮 |
| 蛋白质摄入 | 1.6–2.2 g/kg 体重 | 1.4–2.0 g/kg 体重 | 孙的参考值 140–150 g/日 |
| 抗阻训练频率 | 3–4 次/周 | 3–4 次/周 | 每次 30 分钟即可 |
| 复合动作占比 | ≥ 60% | ≥ 60% | 深蹲、硬拉、卧推、划船、推举 |
| 渐进超载步长 | 2.5 kg 或 +1 次 / 周 | 1–2.5 kg | 核心中的核心 |
| 睡眠 | 7–8 小时 | 7–8 小时 | 用 Oura Ring 等可穿戴监测 |
| 补剂 | 蛋白粉 25 g + 肌酸 5 g | 同左酌情 | 可选，非必需 |

> 以上为公开资料整理的通用参考区间，**不构成医疗建议**。
> 有基础疾病者请遵医嘱。
