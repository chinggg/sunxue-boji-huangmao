# 每日循环

> 目标不是某一天做得很多，而是**这套动作能循环一年**。
> 可循环比强度重要。

---

## 晨间 · 10 分钟

| 时间 | 动作 | 产出 |
|---|---|---|
| 2' | 看一眼昨天的睡眠数据（可穿戴 / 手记） | 一个数 |
| 3' | 确认今天的主项训练动作与目标重量 | 一行计划 |
| 5' | 读一条补丁日志或一句格言 | 认知校准 |

```bash
python3 scripts/sunxue.py quote
```

---

## 训练 · 30 分钟

| 阶段 | 时长 | 动作 |
|---|---|---|
| 热身 | 5' | 关节活动 + 空杠深蹲 |
| 主项 | 15' | 深蹲 / 硬拉 4 × 6–8 |
| 辅项 | 7' | 俯卧撑 / 引体 / 划船 3 × 10–12 |
| 核心 | 3' | 平板支撑 / 悬垂举腿 3 × 45s |

**唯一硬指标：渐进超载。**

```
本周能标准完成 4×8 → 下周 +2.5 kg（下肢）/ +1.25 kg（上肢）或 +1 次
本周只完成部分组 → 维持重量，补满次数
本周动作质量下滑 → 减重 10%，先修质量
```

## 饮食 · 拍照即记录

```
餐前：拍一张完整餐桌 → 发给 AI
餐后：拍一张残局    → 发给 AI
```

AI 返回：热量、蛋白质、进食顺序建议。

```bash
# 用 prompts/03-饮食卡路里识别.md 里的 Prompt
```

**每日核对**

| 项目 | 目标 | 实际 |
|---|---|---|
| 蛋白质 | ____ g（体重 × 1.6–2.2） | ____ g |
| 总热量 | ____ kcal | ____ kcal |

> 差得太多不要自责，改**结构**（比如午餐固定加一份鸡胸/鸡蛋），
> 不要靠意志力补。

## 晚间 · 10 分钟

```bash
python3 scripts/sunxue.py today --weight 75 --out journal/daily/$(date +%F).md
```

填三件事：

1. **薄肌**：今天练了什么、重量多少、蛋白质多少
2. **孙学**：今天的认知补丁（我以前错在哪）+ 开图动作
3. **黄毛**：今天有没有做「面子过不去但正确」的事；情绪成本几分

**写不出来怎么办**：只写一句「今天什么都没做」也算完成。
**连续性 > 完整性。**

## 周末 · 30 分钟复盘

```bash
python3 scripts/sunxue.py diag     # 三维打分
python3 scripts/sunxue.py body     # 身体进度
python3 scripts/sunxue.py 37       # 决策状态
```

| 检查项 | 标准 |
|---|---|
| 训练次数 | ≥ 3 次 / 周 |
| 总容量 | 比上周 +5% 以上 |
| 蛋白质达标天数 | ≥ 5 / 7 |
| 平均睡眠 | ≥ 7 小时 |
| 认知补丁 | ≥ 1 条 |
| 黄毛日志 | ≥ 1 条 |
| 能量审计 | 砍掉一件无贡献的事 |

## 循环的三个原则

**1 · 可循环 > 强度**
一次练 90 分钟然后躺三天，不如每天 30 分钟连续一年。

**2 · 连续性 > 完整性**
断一天，系统信用掉一格。宁可只写一行，不要空一天。

**3 · 数据留在本地**
所有记录是本地 Markdown。今天用 Claude，明天想换 Gemini，
新的 Agent 读入 `.md` 就能无缝接管。

> **核心原则：数据本地化，模型解耦。**

---

## 卡住时的排查顺序

```
连续两周无进展
   │
   ├─ 睡眠 < 7 小时        → 先修睡眠，不是修训练
   ├─ 蛋白质 < 1.6 g/kg    → 先改饮食结构，不是加训练量
   ├─ 热量缺口 > 500 kcal  → 缺口过大，在消耗肌肉存量
   └─ 三者都正常           → deload 一周（减量 40%）
```

```
连续两周没写记录
   │
   └─ 目标定太大 → 只要求「写一行」
```

```
连续两周没做黄毛动作
   │
   └─ 难度选太高 → 降到 ★☆☆，今天下午就做
```
