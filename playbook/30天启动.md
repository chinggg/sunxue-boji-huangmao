# 30 天启动手册

> 顺序原理：**薄肌（7–14 天可见反馈）→ 孙学（并行，成本近乎为零）→ 黄毛（阻力最大，需先建立系统信用）**

## 为什么是这个顺序

| 组件 | 首次反馈周期 | 启动成本 | 主观阻力 | 排序 |
|---|---|---|---|---|
| 薄肌 | 7–14 天 | 每天 30 分钟 | 低 | **1** |
| 孙学 | 30–90 天 | 一本书 + 思考 | 中 | **2（并行）** |
| 黄毛 | 即时 | 一次面子成本 | **高** | **3** |

先装薄肌，是为了**用可测量的正反馈建立系统信用**。
有了信用，第二周你才敢去做那件「面子过不去」的事。

## D1–D7 · 建档期

**目标**：建立本地 Markdown 数据仓。这是整套系统的地基。

### 必做

- [ ] **D1** 建立目录结构（见下方）
- [ ] **D1** 记录一次基线：身高、体重、体脂、深蹲/硬拉 5RM
- [ ] **D1–D7** 每天记录睡眠、饮食、训练（哪怕只写三行）
- [ ] **D3** 第一次使用 `sunxue.py diag` 和 `sunxue.py body`
- [ ] **D7** 第一次周复盘

### 目录结构

```
sunxue-journal/
├── README.md              你的个人总纲（从仓库 README 精简而来）
├── daily/
│   └── 2026-10-10.md      日报（templates/daily.md）
├── health/
│   └── 2026-10.md         健康数据仓（templates/health-data.md）
├── decisions/
│   └── 换赛道.md           决策档案（templates/decision-37.md）
├── weekly/
│   └── W01.md             周复盘（templates/weekly-review.md）
└── patches.md             补丁日志
```

### 一键生成

```bash
mkdir -p sunxue-journal/{daily,health,decisions,weekly}
python3 scripts/sunxue.py today --weight 75 --out sunxue-journal/daily/$(date +%F).md
```

### 验收标准

✅ 连续 7 天有记录，哪怕某天只写了一句「今天什么都没做」。
**连续性比完整性重要。** 断一天，系统的信用就掉一格。

## D1–D30 · 薄肌启动

**目标**：每天 30 分钟抗阻复合动作，达成渐进超载。

### 训练模板

| 阶段 | 时长 | 动作 |
|---|---|---|
| 热身 | 5' | 关节活动 + 空杠深蹲 |
| 主项 | 15' | 深蹲 / 硬拉（复合）4 × 6–8 |
| 辅项 | 7' | 俯卧撑 / 引体 / 划船 3 × 10–12 |
| 核心 | 3' | 平板支撑 / 悬垂举腿 3 × 45s |

### 三条铁律

1. **复合动作 ≥ 60% 训练量** —— 深蹲、硬拉、卧推、划船、推举
2. **每周必须有一次渐进超载** —— +2.5 kg 或 +1 次
3. **孤立动作是点缀** —— 弯举、飞鸟不进主项

### 蛋白质

```bash
python3 scripts/sunxue.py body   # 拿到你的每日蛋白质目标
```

参考：1.6–2.2 g / kg 体重。孙宇晨公开数据为 75 kg → 140–150 g/日。

### 验收标准

✅ 30 天后，深蹲或硬拉的 5RM 至少提升 10%（或总容量提升 15%）。

## D3–D14 · 孙学安装

**目标**：用 AI 推演 100 个赛道，产出个人 Benchmark 表。

### 动作

- [ ] **D3** 读 `docs/02-孙学-认知内核.md`
- [ ] **D5** 跑一次 `prompts/01-现状诊断.md`
- [ ] **D7–D14** 用 `prompts/05-全图插眼100专业.md` 分 5 批推演 100 个赛道
- [ ] **D14** 产出 Top 10 表格 + 前 3 名 Benchmark
- [ ] **D14** 跑一次 `python3 scripts/sunxue.py roi`，算出你当前卡点的真实 ROI

### 关键产出

一份 **100 行赛道推演表**，含：10 年需求曲线 / AI 替代风险 / 准入门槛 /
边际成本 / 地理约束 / 复利属性 / 饱和度。

> 把这份表**公开写出来**。不为流量，为形式化存档 ——
> 不被形式化的认知，在下一纪元等同于不存在。

### 验收标准

✅ 能说出 3 个确定增长的赛道，且每个都有数据支撑而非感觉。

## D8–D30 · 黄毛上线

**目标**：主动做一件「面子过不去但正确」的事，记录情绪成本归零。

### 为什么排在第 8 天之后

因为你需要在前 7 天里积累**系统信用** ——
你亲眼看到体重掉了 0.8 kg、深蹲加了 5 kg、数据仓连续 7 天不断。
这时候你才有底气对嘲讽说：这是 A 类噪音。

### 动作清单（选一件，本周期内完成）

| 难度 | 动作 |
|---|---|
| ★☆☆ | 把你正在做的事公开告诉一个可能不理解你的朋友 |
| ★★☆ | 发第一条公开内容（文章/视频/仓库），不解释、不预告 |
| ★★★ | 主动联系一个你觉得「够不着」的人 |
| ★★★★ | 放弃一个体面但无复利的身份/职位/关系 |

### 记录

```markdown
## 黄毛日志
日期：
做了什么：
事前预估情绪成本（0-10）：
事后实际情绪成本（0-10）：
外界反馈：
噪音分类：A / B / C
是否影响执行：是 / 否
```

### 验收标准

✅ 连续 5 次记录后，**事前预估情绪成本显著下降**。
这说明护甲正在成型。

## D30 · 首次复算

**目标**：把 30 天数据喂给 3 个大模型，取中策，开始 Tuning。

### 步骤

1. 打包你的 `daily/` + `health/` 全部内容
2. 分别发给 Claude / GPT / Gemini，各跑一次 `prompts/02-三策推演.md`
3. 对比三家的推荐策与 ROI 估值，**记录分歧点**
4. 取中策（或三家中至少两家收敛的那一策）
5. 写出未来 8 周的执行表与止损条件

## 30 天验收清单

| # | 验收项 | 通过 |
|---|---|---|
| 1 | 连续 30 天数据记录，断档 ≤ 2 天 | ☐ |
| 2 | 深蹲/硬拉 5RM 提升 ≥ 10% | ☐ |
| 3 | 蛋白质达标天数 ≥ 20 / 30 | ☐ |
| 4 | 100 赛道推演表已完成 | ☐ |
| 5 | 完成 1 件「面子过不去但正确」的事 | ☐ |
| 6 | 黄毛日志 ≥ 5 条，预估成本下降 | ☐ |
| 7 | 补丁日志 ≥ 2 条 | ☐ |
| 8 | 三模型交叉验证完成，已取中策 | ☐ |

**≥ 6 项通过** → 系统已成型，进入长期循环。
**< 4 项** → 回到 D1，先只做一件事：连续 7 天记录。

## 常见失败模式

| 症状 | 根因 | 修正 |
|---|---|---|
| 第 3 天就断了 | 目标定太大 | 只要求「写一行」，连续性 > 完整性 |
| 一直在练，没变化 | 没有渐进超载 | 每周必须加重量或加次数，写进表格 |
| 100 赛道推不动 | 一次要太多 | 拆成每天 10 个，10 天完成 |
| 黄毛那件一直没做 | 等你「准备好」 | 选 ★☆☆ 难度，今天下午就做 |
| 数据写了但没用 | 没做复算 | D30 必须喂给模型，否则数据只是日记 |
