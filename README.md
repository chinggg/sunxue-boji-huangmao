## 三、前提 · 为什么高富帅过时了

> 这一节是整套系统的**诊断前提**，不是卖点。想直接要方法可以看 [第九节](#九30-天启动)。

社会从增量时代切到存量时代，只发生了一件事：**旁观者的羡慕，不能扫码支付了**。  
（存量时代在中文互联网上也被称作「大压抑时代」，完整诊断见 [`docs/01`](docs/01-总纲-大压抑时代诊断.md)）

|      | 增量时代                  | 存量时代        |
| ---- | --------------------- | ----------- |
| 视觉资产 | 信用放大器 —— 银行敢放款、投资人敢打钱 | 变现通道关闭，变成负债 |
| 最优策略 | 维护高维护成本人设             | **把人设预算清零** |

一句话：**资源花在「让人羡慕」上是消费，花在「最后站着的是我」上是投资。**

## 四、三条公理

**公理一 · 沉没成本公理**  
增量时代你购买的是「被羡慕」的期权。存量时代，这份期权到期归零，而维持它的现金流一分不少。

> 虚荣是最大的负债，生存才是唯一的硬通货。

**公理二 · 可替代性公理**  
凡是要求先天条件才能入场的标准，都是让大多数人给少数人当观众的门票。

> 高富帅崇拜的本质，是让大多数人给少数人当观众。

**公理三 · 本地化公理**  
数据的控制权必须留在本地 Markdown。模型只是可替换的算力插件。

> 只要文件是 .md，随时能换 API。今天 Claude 好用就用 Claude，明天 Gemini 更强就换 Gemini。

## 五、核心方程

### 4.1 孙学 ROI 方程

```
                      结果收益 R × 实现概率 P
    ROI  =  ─────────────────────────────────────────
            直接成本 C + 评价成本 E + 切换成本 S
```

- **黄毛** 令 `E → 0`：把「他人的评价」从成本项里彻底划掉
- **轻资产** 令 `S → 0`：不买房不买车不过早锁定流动性
- 于是 `ROI → R·P / C`，**同样的能力，拿到完全不同的结果**

### 4.2 行动成本方程

```
    C(action) = C(task) + C(face) + C(permission)
```

大部分人不是败在 `C(task)`，而是败在「面子上过不去」和「还没等到体面的出场时机」。  
黄毛令后两项归零。

### 4.3 薄肌配置方程

| 身体成分     | 财务映射   | 说明                                  |
| -------- | ------ | ----------------------------------- |
| **肌肉**   | 美金现金存量 | 大病/高压/应激时代谢优先扣肌肉去修复器官，这是你的储备金       |
| **体脂**   | 不良负债   | 占额度不产生收益                            |
| **训练成本** | 利息     | 大肌肉 = 高存量 + **高利息**；薄肌 = 足够存量 + 低利息 |

> 肌肉还是身体被动燃脂的「红莲斗篷」—— 睡觉时也在消耗热量、改善胰岛素敏感性。

### 4.4 寿命 100 分定量模型

<div align="center">  
<img src="assets/lifespan.svg?v=2" width="80%" alt="寿命100分模型">  
</div>

| 模块             | 分值       | 获取方式               |
| -------------- | -------- | ------------------ |
| 心肺功能           | **25 分** | 抗阻复合动作（深蹲/硬拉）可同时拿满 |
| 肌肉质量           | **25 分** | 同上，**一次性拿满前 50 分** |
| 器官维护 / 抗衰 / 基因 | 50 分     | 主动数据排雷 + 长期主义      |

> 单纯有氧在提升心肺的同时造成肌肉流失。抗阻训练是投资回报率最高的杠杆。

**⚠️ 司美格鲁肽陷阱**  
`越打药 → 基础代谢断崖下跌 → 停药迅速反弹 → 肌肉更少 → 晚年肌无力、极易骨折卧床`  
药物在削减脂肪的同时大幅削减肌肉 —— 你在借未来的寿命还今天的体重。

## 六、资产四象限：你的钱和时间花在了哪一格

<div align="center">  
<img src="assets/quadrant.svg?v=2" width="80%" alt="资产四象限">  
</div>

|         | **为自己服务**       | **为观众服务**          |
| ------- | --------------- | ------------------ |
| **高维护** | 过度增肌（能力很强，成本失控） | **高富帅人设** ← 最危险的格子 |
| **低维护** | **薄肌**（功能型资产 ✅） | **黄毛**（把评价成本清零 ✅）  |

> 大肌肉是展示型资产：训练时长、饮食管理、维持成本都高，收益是被看见。  
> 薄肌是功能型资产：低维护、高续航、随时能跑。  
> **同样是身体，一个为观众服务，一个为自己服务。**

<div align="center">

**孙学给方向 → 薄肌给燃料 → 黄毛给护甲 → 结果回到孙学校准。**

| 缺失        | 症状           | 诊断名         |
| --------- | ------------ | ----------- |
| 无孙学 + 有薄肌 | 练了五年，还是为观众服务 | **健身房打工人**  |
| 无孙学 + 有黄毛 | 冲劲十足，方向为零    | **纯莽夫**     |
| 无薄肌 + 有孙学 | 认知跑太快，身体先崩   | **碳基服务器宕机** |
| 无黄毛 + 有孙学 | 全看懂了，但不敢做    | **被舆论劝退者**  |
| 无黄毛 + 无薄肌 | 知道答案却上不了场    | **观众席常客**   |

> 当一个人兼具高认知与好体魄时，他在华语社会中**极易受到质疑**。  
> 黄毛理论就是这套系统的精神护甲。

## 八、决策：37% 参照系模型

<div align="center">  
<img src="assets/rule37.svg?v=2" width="80%" alt="37% 参照系决策模型">  
</div>

面对 100 个选项（100 套房 / 100 个专业 / 100 份工作）：

1. **前 37%（约前 30 个）绝不做最终决定** —— 它们唯一的用途是帮你建立 Benchmark
2. **从第 31 个开始**，一旦出现综合指标超过参照系的最优解 —— **立刻出手**

> 决策失败只有两种：第一套就盲目下定（参照系缺失），或者看满 100 套（选择瘫痪）。

**配套动作：全图插眼**  
别闭门造车。像 RTS/MOBA 一样，先造几个移动速度极快的侦察兵去插眼 ——  
用 AI 逐一推演未来 10 年 100 个专业的就业与行业趋势，**把地图全开**，看见资源与风险分布后再做选择。

## 十四、一起进化：Issue、PR 与 Roadmap

这套系统的价值不在它现在多完整，而在**它能不能被别人改得更好**。任何形式的参与都欢迎。

**最受欢迎的三类贡献**

| 类型 | 说明 | 入口 |
|---|---|---|
| 🥇 **反驳** | 你不同意某个论断，或发现逻辑漏洞 —— 这是最欢迎的一类 | PR 到 `docs/09-边界-争议与反面.md` |
| 🥈 **补一手材料** | 孙宇晨 / 邵艾伦的原始发言、更早的出处考据、其他整理版本 | Issue，或 PR 到 `docs/` 并在文末标注来源 |
| 🥉 **加能跑的东西** | CLI 新子命令、实测过的 Prompt、更好用的模板、新图 | `scripts/` · `prompts/` · `templates/` · `assets/` |

**开 Issue**：bug、理论漏洞、想要的新维度、看不懂的段落 —— 都算 Issue。不用措辞客气，直接说哪里不对。

**提 PR**：详见 [`CONTRIBUTING.md`](CONTRIBUTING.md)。三条硬约束 —— `scripts/sunxue.py` 保持零第三方依赖且兼容 Python 3.8+；新增 SVG 必须能过 XML 解析；引用他人观点要标来源。一个 PR 一件事，并在 PR 里说明你在什么场景下真用过。

**Roadmap**

- [ ] 英文版 README / docs（附术语对照表）
- [ ] `scripts/sunxue.py` 增加 TDEE 与周期化训练计划生成
- [ ] `prompts/` 从 6 个扩到 12 个（可以直接认领其中一个）
- [ ] 补一节「关系与亲密关系的边界」—— 黄毛清零的是**无关者**的评价，这条线目前只有一句硬边界
- [ ] 补齐原始访谈逐字稿（4h22m，目前没有字幕轨，谁有转写欢迎直接 PR）

> 版本更新与补丁日志记在 [`docs/08-Small-Ego与版本更新.md`](docs/08-Small-Ego与版本更新.md)。
